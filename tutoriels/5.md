# Tutoriel 5 — Intégration Projet Réel (Page Détail Produit)

## 🎯 Objectifs pédagogiques

* Structurer une **page complète** (SEO, accessibilité, dark mode).
* Intégrer Tailwind dans un **framework** (Laravel + Vite).
* Construire des **composants réutilisables** (galerie, badges, onglets, avis).
* Gérer des **interactions** sans lourdeur (group/peer/ARIA, JS minimal).
* Préparer la page pour la **prod** (build, purge, meta, JSON-LD).

## ✅ Pré-requis

* Tutoriels 1 → 4 (dont design system `btn-*`, `card-*`, `badge`).
* Node, npm, et projet Laravel (ou HTML si tu choisis la variante B).

---

## 🧭 Plan rapide

1. Structure & routing
2. Layout global + SEO/Dark
3. Section par section (Gallery, Infos, Prix & Panier, Onglets, Avis, Produits liés)
4. Accessibilité + JSON-LD
5. Build & vérifs

<script>
  // Galerie (thumb → image principale)
  document.querySelectorAll('[data-image]').forEach(btn => {
    btn.addEventListener('click', () => {
      document.getElementById('mainImage').src = btn.dataset.image;
    });

  // Onglets
  const tabs = document.querySelectorAll('.tab-btn');
  const panels = {
    desc: document.getElementById('tab-desc'),
    specs: document.getElementById('tab-specs'),
  };
  tabs.forEach(t => t.addEventListener('click', () => {
    tabs.forEach(x => x.classList.remove('active'));
    t.classList.add('active');
    Object.values(panels).forEach(p => p.classList.add('hidden'));

</script>

## ♿ Accessibilité & SEO rapides

* Boutons avec `aria-pressed`, `aria-label` et **focus-visible**.
* Titres hiérarchisés (`h1`, `h2`) et `nav` breadcrumb.
* Attributs `alt` pour images.
* **SEO** : `meta description`, `og:*` et **JSON-LD** produit :

```html
<script type="application/ld+json">
{
  "@context": "https://schema.org/",
  "@type": "Product",
  "name": "Casque Bluetooth X300",
  "image": ["/images/x300-1.jpg","/images/x300-2.jpg"],
  "description": "Casque sans fil ANC, 20h d’autonomie, USB-C.",
  "brand": {"@type": "Brand","name": "BrandX"},
  "offers": {"@type": "Offer","priceCurrency": "MAD","price": "799","availability": "https://schema.org/InStock"},
  "aggregateRating": {"@type":"AggregateRating","ratingValue":"4.4","reviewCount":126}
}
</script>
```

## 🧪 Exercices (20–40 min)

1. **Zoom image plein écran**

   * Au clic sur l’image principale → overlay fullscreen (`fixed inset-0 bg-black/80`) avec l’image en grand + bouton fermer.

2. **Sélecteur de couleur**

   * Ajoute des pastilles (`bg-black`, `bg-white`, `bg-rose-600`), applique une **bordure active** et change la vignette principale.

3. **Badge stock dynamique**

   * Si quantité < 5 → badge “Stock limité” (`bg-amber-100 text-amber-700`).

4. **Produits liés (squelette)**

   * En attendant les données, affiche 3 “skeletons” (`animate-pulse bg-gray-200 dark:bg-gray-700 h-40 rounded-xl`).
