# Tutoriel 4 — Setup local, Design System & Plugins (Tailwind)

## 🎯 Objectifs pédagogiques

* Installer Tailwind **en local** (Node, PostCSS).
* Configurer `tailwind.config.js` (couleurs, polices, breakpoints, dark mode).
* Créer des **composants réutilisables** avec `@apply`.
* Utiliser des **plugins officiels** (Forms, Typography, Aspect Ratio).
* Gérer le **build dev/prod** (purge = `content`).

## ✅ Pré-requis

* Tutoriels 1–3.
* Node.js ≥ 18 (vérifier `node -v`, `npm -v`).
* Éditeur (VS Code + extension Tailwind CSS).

## 1) ⚙️ Installation

```bash
mkdir tuto4-tailwind && cd tuto4-tailwind
npm init -y
npm install -D tailwindcss postcss autoprefixer
npx tailwindcss init -p
```

> La commande `-p` crée aussi `postcss.config.js`.

---

## 2) 🛠️ Configuration Tailwind

### `tailwind.config.js`

```js
/** @type {import('tailwindcss').Config} */
module.exports = {
  darkMode: 'class', // dark activé par classe (ajouter .dark sur <html>)
  content: [
    "./public/**/*.{html,js}",   // Purge: fichiers scannés
  ],
  theme: {
    extend: {
      colors: {
        // Palette marque
        brand: {
          50:  '#eef2ff',
          100: '#e0e7ff',
          500: '#6366f1',   // primaire
          600: '#4f46e5',
          700: '#4338ca',
        },
      },
      fontFamily: {
        // Police globale (inter, system fallback)
        sans: ["Inter", "ui-sans-serif", "system-ui", "Segoe UI", "Roboto"],
      },
      boxShadow: {
        card: "0 8px 24px rgba(0,0,0,0.08)",
      },
      borderRadius: {
        xl2: "1.25rem",
      },
    },
    container: {
      center: true,
      padding: "1rem",
      screens: { sm: "640px", md: "768px", lg: "1024px", xl: "1280px" },
    },
  },
  plugins: [
    require('@tailwindcss/forms'),
    require('@tailwindcss/typography'),
    require('@tailwindcss/aspect-ratio'),
  ],
}
```

### `postcss.config.js`

```js
module.exports = {
  plugins: {
    tailwindcss: {},
    autoprefixer: {},
  },
}
```

## 3) 🎨 CSS source & `@apply`

### `src/input.css`

```css
@tailwind base;
@tailwind components;
@tailwind utilities;

/* ===== Design System (utilisant @apply) ===== */

@layer components {
  .btn {
    @apply inline-flex items-center justify-center gap-2
           px-4 py-2 rounded-lg font-medium
           transition duration-200 focus:outline-none focus-visible:ring-2;
  }
  .btn-primary {
    @apply btn bg-brand-600 text-white hover:bg-brand-700
           focus-visible:ring-brand-400;
  }
  .btn-outline {
    @apply btn border border-gray-300 hover:bg-gray-50
           dark:border-gray-700 dark:hover:bg-gray-800;
  }

  .card {
    @apply bg-white dark:bg-gray-800 rounded-xl2 shadow-card overflow-hidden border border-transparent dark:border-gray-700;
  }
  .card-body {
    @apply p-6;
  }
  .badge {
    @apply inline-block text-xs px-2 py-0.5 rounded bg-emerald-100 text-emerald-700 dark:bg-emerald-900/30 dark:text-emerald-300;
  }
}
```

> `@layer components` te permet de créer **tes classes maison** avec `@apply` pour éviter de répéter des utilitaires.

## 5) 🏗️ Build & scripts NPM

### `package.json` (scripts)

```json
{
  "name": "tuto4-tailwind",
  "version": "1.0.0",
  "private": true,
  "scripts": {
    "dev": "npx tailwindcss -i ./src/input.css -o ./dist/output.css --watch",
    "build": "NODE_ENV=production npx tailwindcss -i ./src/input.css -o ./dist/output.css --minify"
  },
  "devDependencies": {
    "autoprefixer": "^10.4.20",
    "postcss": "^8.4.47",
    "tailwindcss": "^3.4.13",
    "@tailwindcss/forms": "^0.5.7",
    "@tailwindcss/typography": "^0.5.12",
    "@tailwindcss/aspect-ratio": "^0.4.2"
  }
}
```

Lance :

```bash
npm run dev    # en développement (watch)
# ou
npm run build  # pour production (minifié)
```

> **Important (purge)** : Tailwind supprime les classes non utilisées en se basant sur `content` dans `tailwind.config.js`. Assure-toi que **tous** tes chemins de fichiers HTML/JS sont listés.

## 6) 🔌 Intégration Laravel (option rapide)

> Si tu utilises Laravel + Vite.

```bash
# Dans un projet Laravel existant
npm install -D tailwindcss postcss autoprefixer @tailwindcss/forms @tailwindcss/typography @tailwindcss/aspect-ratio
npx tailwindcss init -p
```

* `tailwind.config.js` → adapte `content` :

```js
content: [
  "./resources/views/**/*.blade.php",
  "./resources/js/**/*.js",
  "./resources/css/**/*.css",
],
darkMode: 'class',
plugins: [
  require('@tailwindcss/forms'),
  require('@tailwindcss/typography'),
  require('@tailwindcss/aspect-ratio'),
],
```

* `resources/css/app.css` :

```css
@tailwind base;
@tailwind components;
@tailwind utilities;

@layer components {
  .btn { @apply inline-flex items-center justify-center gap-2 px-4 py-2 rounded-lg font-medium transition duration-200 focus:outline-none focus-visible:ring-2; }
  .btn-primary { @apply btn bg-brand-600 text-white hover:bg-brand-700 focus-visible:ring-brand-400; }
}
```

* `vite.config.js` (par défaut OK).
* Dans ton layout Blade :

```blade
<!DOCTYPE html>
<html lang="fr" class="">
  <head>
    @vite(['resources/css/app.css','resources/js/app.js'])
  </head>
  <body class="bg-gray-50 dark:bg-gray-900">
    <button class="btn-primary">Action</button>
  </body>
</html>
```

Puis :

```bash
npm run dev   # ou npm run build
```

## 🛠️ Dépannage rapide

* **Classes ignorées en prod** → Ajoute les chemins manquants dans `content`.
* **Dark ne marche pas** → `darkMode: 'class'` + `.dark` sur `<html>` (ou sur `<body>`).
* **Styles plugins absents** → Vérifie `require('@tailwindcss/...')` dans `plugins`.
* **Fonts non appliquées** → Charge la fonte (ex. Inter via `<link>` Google Fonts ou fichier local) et configure `fontFamily`.
