# Tutoriel 1 — Introduction & bases de Tailwind CSS

## 🎯 Objectif pédagogique

* Comprendre la philosophie **utility-first**.
* Installer Tailwind **via CDN** (zéro build).
* Créer une **carte produit** propre et responsive minimale.

## ✅ Pré-requis

* Savoir créer un fichier `index.html`.
* Navigateur moderne (Chrome/Edge/Firefox).
* (Optionnel) VS Code + extension **Live Server**.

## 🗂️ Mise en place (5 min)

1. Crée un dossier : `projet-tailwind-01/`
2. Ajoute un fichier : `index.html`

Colle ce **boilerplate** minimal (CDN officiel) :

```html
<!DOCTYPE html>
<html lang="fr">
<head>
  <meta charset="UTF-8" />
  <meta name="viewport" content="width=device-width, initial-scale=1" />
  <title>Détail Produit — Tuto 1</title>
  <!-- Tailwind CDN -->
  <script src="https://cdn.tailwindcss.com"></script>
</head>
<body class="bg-gray-50 min-h-screen flex items-center justify-center p-4">
  <main id="app" class="w-full max-w-sm"></main>
  <script>
    // Petit helper pour injecter le contenu étape par étape
    const app = document.getElementById('app');
  </script>
</body>
</html>
```

---

## 🧱 Étape 1 — Structure de la carte (HTML pur)

Remplace le `<script>` par ce contenu (ou colle directement le HTML dans `<main>` si tu préfères) :

```html
<article class="bg-white rounded-2xl shadow-md overflow-hidden">
  <img src="https://placeholder.co/640x360" alt="Image produit" class="w-full aspect-video object-cover">
  <div class="p-4">
    <h1 class="text-xl font-semibold text-gray-900">Casque Bluetooth X300</h1>
    <p class="mt-1 text-gray-600 text-sm">
      Réduction de bruit active, 20h d’autonomie.
    </p>

    <div class="mt-3 flex items-center justify-between">
      <span class="text-indigo-600 font-bold text-lg">799 DH</span>
      <span class="text-green-600 text-sm font-medium">En stock</span>
    </div>

    <button class="mt-4 w-full rounded-lg bg-indigo-600 text-white py-2 font-medium hover:bg-indigo-700 transition">
      Ajouter au panier
    </button>
  </div>
</article>
```

> 💡 Lecture des classes :
> `bg-white`, `rounded-2xl`, `shadow-md` = **carte** ;
> `p-4`, `mt-4` = **espacements** ;
> `text-*`, `font-*` = **typo** ;
> `flex`, `items-center`, `justify-between` = **layout**.

---

## 📱 Étape 2 — Un soupçon de responsive (5 min)

Ajoute un **wrapper** pour élargir sur écrans moyens :

```html
<main class="w-full max-w-sm md:max-w-2xl">
  <!-- ta carte ici -->
</main>
```

Et passe la carte en **grid** à 2 colonnes sur `md:` :

```html
<article class="bg-white rounded-2xl shadow-md overflow-hidden md:grid md:grid-cols-2">
  <img ... class="w-full h-full object-cover md:aspect-auto">
  <div class="p-4"> ... </div>
</article>
```

---

## ✨ Étape 3 — États & micro-interactions (5 min)

Rends le bouton plus vivant :

```html
<button
  class="mt-4 w-full rounded-lg bg-indigo-600 text-white py-2 font-medium
         hover:bg-indigo-700 active:bg-indigo-800 focus:outline-none
         focus:ring-2 focus:ring-indigo-400 transition duration-200">
  Ajouter au panier
</button>
```

> Concepts : `hover:`, `active:`, `focus:`, `focus:ring`, `transition`, `duration-200`.

---

## 🌙 Étape 4 — Dark mode (en 2 lignes)

Active le mode sombre par classe (simple pour un tuto) :

1. Ajoute `class="dark"` sur `<html>` pour le forcer (ou fais un petit toggle JS).
2. Ajoute des variantes `dark:*` :

```html
<body class="bg-gray-50 dark:bg-gray-900 min-h-screen flex items-center justify-center p-4">
  <article class="bg-white dark:bg-gray-800 rounded-2xl shadow-md overflow-hidden md:grid md:grid-cols-2">
    <img ...>
    <div class="p-4">
      <h1 class="text-xl font-semibold text-gray-900 dark:text-white">Casque Bluetooth X300</h1>
      <p class="mt-1 text-gray-600 dark:text-gray-300 text-sm">Réduction de bruit active, 20h d’autonomie.</p>
      <div class="mt-3 flex items-center justify-between">
        <span class="text-indigo-600 font-bold text-lg">799 DH</span>
        <span class="text-green-600 text-sm font-medium">En stock</span>
      </div>
      <button class="mt-4 w-full rounded-lg bg-indigo-600 text-white py-2 font-medium hover:bg-indigo-700 active:bg-indigo-800 focus:outline-none focus:ring-2 focus:ring-indigo-400 transition duration-200">Ajouter au panier</button>
    </div>
  </article>
</body>
```

*(Optionnel : écris un mini script pour basculer `document.documentElement.classList.toggle('dark')` sur un bouton “Dark”.)*

## 🧰 Aide-mémoire des classes utilisées

* **Couleurs** : `bg-gray-50`, `bg-white`, `text-gray-900`, `text-gray-600`, `text-indigo-600`, `text-green-600`
* **Espacement** : `p-4`, `mt-1`, `mt-3`, `mt-4`, `gap-*`
* **Typos** : `text-sm`, `text-lg`, `text-xl`, `font-medium`, `font-semibold`, `leading-*`
* **Layout** : `flex`, `items-center`, `justify-between`, `grid`, `md:grid-cols-2`, `max-w-sm`, `md:max-w-2xl`
* **Cartes** : `rounded-2xl`, `shadow-md`, `overflow-hidden`
* **Images** : `w-full`, `aspect-video`, `object-cover`
* **États** : `hover:*`, `active:*`, `focus:*`, `focus:ring-*`, `transition`, `duration-200`
* **Dark** : `dark:bg-gray-900`, `dark:bg-gray-800`, `dark:text-white`, `dark:text-gray-300`

---

## ❗ Erreurs fréquentes & fixes

* **Rien ne s’affiche “stylé”** → Vérifie la ligne CDN `<script src="https://cdn.tailwindcss.com"></script>`.
* **Dark mode ne marche pas** → Il faut **ajouter la classe `dark` sur `<html>`** (ou via JS) pour ce tuto.
* **Image déformée** → Utilise `object-cover` + `aspect-video` (ou fixe la hauteur).
