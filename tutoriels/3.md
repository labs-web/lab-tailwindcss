## 1) États simples + transitions

### Bouton interactif (états + transitions)

```html
<button
  class="inline-flex items-center gap-2 px-4 py-2 rounded-lg
         bg-indigo-600 text-white font-medium
         hover:bg-indigo-700 active:bg-indigo-800
         focus:outline-none focus-visible:ring-2 focus-visible:ring-indigo-400
         disabled:opacity-50 disabled:cursor-not-allowed
         transition-colors duration-200">
  Acheter
</button>
```

**Clés :**

* `focus-visible:` pour l’accessibilité (ne montre l’anneau qu’au clavier).
* `transition-colors duration-200` pour un fondu propre.
* `disabled:*` pour anticiper l’état inactif.

## 2) `group` & `group-hover` (effets coordonnés)

### Carte produit avec effet hover synchronisé

```html
<article class="group relative rounded-2xl overflow-hidden border bg-white shadow-sm
                hover:shadow-lg transition-shadow duration-200
                dark:bg-gray-800 dark:border-gray-700">
  <img
    src="https://via.placeholder.com/640x400"
    alt="Produit"
    class="w-full h-56 object-cover transition-transform duration-300 group-hover:scale-105"
  />

  <div class="p-4">
    <h3 class="text-lg font-semibold dark:text-white">Casque X300</h3>
    <p class="text-sm text-gray-600 dark:text-gray-300">20h autonomie, ANC.</p>
    <div class="mt-3 flex items-center justify-between">
      <span class="text-indigo-600 font-bold text-lg">799 DH</span>
      <a href="#"
         class="opacity-0 group-hover:opacity-100 translate-y-1 group-hover:translate-y-0
                transition-all duration-200 text-sm underline">
        Détails
      </a>
    </div>
  </div>
</article>
```

**Clés :** `group` sur le parent → `group-hover:*` sur les enfants (image + lien).

## 3) `peer` & `peer-checked` (interactions sans JS)


**Clés :** `peer` (input) → `peer-checked:*` sur les siblings.

## 4) `focus-within` (UX formulaires)

```html
<form class="max-w-xl space-y-4">
  <div class="rounded-lg border bg-white dark:bg-gray-800 dark:border-gray-700
              focus-within:ring-2 focus-within:ring-indigo-400">
    <label class="block text-xs text-gray-500 dark:text-gray-400 px-3 pt-2">Email</label>
    <input type="email"
           class="w-full bg-transparent px-3 pb-2 pt-1 outline-none"
           placeholder="vous@exemple.com" />
  </div>

  <button class="px-4 py-2 rounded-lg bg-indigo-600 text-white hover:bg-indigo-700 transition">
    Envoyer
  </button>
</form>
```

**Clés :** `focus-within:*` pour styliser le conteneur quand l’input a le focus.

## 5) Variantes `aria-*` & `data-*` (accessibilité + JS léger)

### Bouton “Ajouter aux favoris” (état ARIA)

```html
<button aria-pressed="false"
        class="px-3 py-1.5 rounded border hover:bg-gray-100 transition
               aria-pressed:bg-rose-600 aria-pressed:text-white
               dark:border-gray-700 dark:hover:bg-gray-700/50">
  ♥ Favori
</button>

<script>
  document.querySelectorAll('[aria-pressed]').forEach(btn => {
    btn.addEventListener('click', () => {
      const v = btn.getAttribute('aria-pressed') === 'true';
      btn.setAttribute('aria-pressed', (!v).toString());
    });
  });
</script>
```

**Clés :** Tailwind applique des styles conditionnels basés sur les attributs ARIA.

## 6) Transitions & micro-animations

### Effet “elevate on hover” (carte)

```html
<article
  class="rounded-2xl border bg-white dark:bg-gray-800 dark:border-gray-700
         shadow-sm hover:shadow-xl transition
         will-change-transform hover:-translate-y-0.5 duration-200">
  <div class="p-6">
    <h3 class="font-semibold dark:text-white">Abonnement Pro</h3>
    <p class="text-gray-600 dark:text-gray-300 text-sm mt-1">
      3 projets, support e-mail.
    </p>
    <button class="mt-4 px-4 py-2 rounded-lg bg-indigo-600 text-white hover:bg-indigo-700 transition">
      Choisir
    </button>
  </div>
</article>
```

### Animations utilitaires intégrées

```html
<div class="flex items-center gap-3">
  <span class="inline-block w-2.5 h-2.5 rounded-full bg-emerald-500 animate-pulse"></span>
  <span class="text-sm text-gray-600 dark:text-gray-300">En ligne</span>
</div>

<button class="px-3 py-1.5 rounded border hover:bg-gray-100 active:animate-bounce">
  Ping
</button>
```

> Rappels : `transition`, `duration-*`, `ease-*`, `transform`, `scale-*`, `translate-*`, `opacity-*`.

## 7) Dark Mode cohérent (sections clés)

Ajoute `dark:` partout où il y a une couleur :

* backgrounds (`dark:bg-gray-900`, `dark:bg-gray-800`)
* textes (`dark:text-white`, `dark:text-gray-300`)
* bordures (`dark:border-gray-700`)
* effets (`dark:hover:bg-gray-700/50`)

> Avec notre bouton “Dark”, on bascule la classe `dark` sur `<html>`.

## 8) Mini-composant “Toast” (apparition/dispersion)

```html
<div id="toast"
     class="pointer-events-none fixed bottom-4 right-4
            bg-gray-900 text-white text-sm px-4 py-2 rounded-lg shadow
            opacity-0 translate-y-2
            transition-all duration-300">
  Ajouté au panier ✅
</div>

<button id="ajouter"
        class="mt-6 px-4 py-2 rounded-lg bg-indigo-600 text-white hover:bg-indigo-700 transition">
  Ajouter au panier
</button>

<script>
  const toast = document.getElementById('toast');
  const add = document.getElementById('ajouter');
  add?.addEventListener('click', () => {
    toast.classList.remove('opacity-0','translate-y-2');
    setTimeout(() => {
      toast.classList.add('opacity-0','translate-y-2');
    }, 1800);
  });
</script>
```

## 🧪 Exercices guidés (15–25 min)

1. **Carte “hover-reveal” complète**

   * Survol de la carte : zoom de l’image + apparition d’un bouton “Voir”.

2. **Accordéon multi-sections**

   * 3 panels indépendants avec `peer` + `peer-checked:block`.
   * Ajoute un **focus-visible** sur chaque label.

3. **Champ de recherche accessible**

   * Conteneur avec `focus-within:ring-2`.
   * Icône loupe (texte “Recherche”) ; placeholder lisible en dark mode.

4. **Dark Mode Toggle**

   * Ajoute une icône 🌙/☀️ qui change selon la présence de la classe `dark`.
   * Assure contrastes AA : `text-gray-300` sur fond `gray-800`.
