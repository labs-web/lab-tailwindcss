# 🎓 **Formation Tailwind CSS — 5 tutoriels progressifs**

---

## 🧱 **Tutoriel 1 — Introduction & philosophie Tailwind CSS**

🎯 *Objectif : comprendre ce qu’est Tailwind, son concept “utility-first”, et créer une première page simple.*

### 🔹 Contenu

1. Qu’est-ce que Tailwind CSS ?

   * Origine du nom (“vent arrière”)
   * Différence avec Bootstrap / CSS classique
   * Avantages et inconvénients

2. Installation express (via CDN)

   * Structure de base d’un fichier HTML
   * Exemple simple : “Carte Produit” ou “Profil utilisateur”

3. Classes utilitaires essentielles

   * Couleurs (`bg-*`, `text-*`)
   * Espacements (`m-*`, `p-*`)
   * Typographie (`font-bold`, `text-xl`)
   * Bordures, coins, ombres (`rounded`, `shadow`)

🧠 **Mini-projet :** créer une carte produit minimaliste (image, titre, prix, bouton)

---

## 🎨 **Tutoriel 2 — Mise en page et responsive design**

🎯 *Objectif : apprendre à structurer et rendre responsive une page complète.*

### 🔹 Contenu

1. Disposition de page

   * Conteneurs, `flex`, `grid`, `gap`
   * Centrage horizontal/vertical

2. Responsive design

   * Préfixes `sm:`, `md:`, `lg:`, `xl:`
   * Cacher/afficher selon la taille d’écran

3. Création d’une page complète

   * Header, contenu principal, footer
   * Exemple : “Page de catalogue produit”

🧠 **Mini-projet :** créer une mini landing page responsive avec 3 sections.

---

## ⚡ **Tutoriel 3 — Interactions et effets visuels**

🎯 *Objectif : dynamiser les interfaces avec les états et transitions Tailwind.*

### 🔹 Contenu

1. États interactifs

   * `hover:`, `focus:`, `active:`
   * États combinés (ex: `hover:scale-105`, `focus:ring-2`)

2. Transitions et animations

   * `transition`, `duration-*`, `ease-*`
   * Animations simples (`animate-bounce`, `animate-pulse`)

3. Gestion des thèmes clairs/sombres

   * Mode sombre (`dark:`)
   * Personnalisation des palettes

🧠 **Mini-projet :** créer une **carte produit interactive** avec effet au survol et thème sombre.

---

## ⚙️ **Tutoriel 4 — Configuration et composants personnalisés**

🎯 *Objectif : installer Tailwind localement et créer un vrai design system.*

### 🔹 Contenu

1. Installation avec Node.js

   * `npm install tailwindcss`
   * Génération du fichier `tailwind.config.js`
   * Structure de projet (src/css, dist/css)

2. Personnalisation du thème

   * Couleurs, polices, breakpoints
   * Utilisation de `@apply` pour créer des classes réutilisables

3. Plugins utiles

   * `@tailwindcss/forms`, `typography`, `aspect-ratio`

🧠 **Mini-projet :** créer un **design system personnel** (boutons, cartes, formulaires).

---

## 🚀 **Tutoriel 5 — Intégration dans un vrai projet**

🎯 *Objectif : utiliser Tailwind dans un framework (Laravel, Vue, React) et optimiser le build.*

### 🔹 Contenu

1. Intégration dans un projet existant

   * Laravel Mix / Vite
   * Structure `resources/css/app.css`
   * Compilation avec `npm run dev`

2. Optimisation de production

   * Purge CSS (`content: []`)
   * Réduction de la taille finale du CSS

3. Bonnes pratiques et architecture

   * Réutilisabilité, cohérence visuelle
   * Accessibilité et performance

🧠 **Projet final :**
Créer une **page “Détail Produit complète”** :
image, titre, description, avis, boutons, responsive, thème sombre, intégré dans Laravel.
